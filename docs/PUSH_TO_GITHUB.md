# PUSH_TO_GITHUB.md — content moved

This document was specific to the legacy Python push-script workflow. For the current MERN project, use standard git:

```bash
git add .
git commit -m "your message"
git push origin main
```

For first-time repo setup, see [CONTRIBUTING.md](CONTRIBUTING.md). For CI behaviour on push, see [BUILD.md](BUILD.md).
